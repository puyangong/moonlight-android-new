# Moonlight 增强版 — 软件使用说明

## 概述

本软件基于开源项目 [Moonlight Android](https://github.com/moonlight-stream/moonlight-android) 进行二次开发，新增了**应用内悬浮窗**、**切后台自动恢复串流**、**长按模式与软键盘集成**等实用功能，大幅提升远程串流的操作便利性。

---

## 一、安装

1. 下载 APK 文件（`app-nonRoot-release.apk`）
2. 允许安装未知来源应用（设置 → 安全 → 允许）
3. 首次启动需与 PC 端的 Sunshine/GeForce Experience 配对
4. ***基础使用：右键：一指长按一指点击；滚动屏幕：两指滑动***

---

## 二、悬浮窗 — 模式控制（屏幕左侧）

悬浮窗 1 是一个**半透明竖条控制面板**，包含 4 个按钮：

| 按钮 | 功能 |
|------|------|
| 拖动柄 | 按住拖动悬浮窗到任意位置，松手后**自动吸附到最近屏幕边缘** |
| 缩放模式 | 单击切换：单指平移屏幕 + 双指缩放画面（双击画面可**一键还原**） |
| 触摸模式 | 单击切换：恢复正常鼠标/触摸操作（**默认开启**） |
| 键盘开关 | 单击打开/关闭软键盘 + 显示/隐藏悬浮窗 2 |

### 2.1 位置记录

- 拖动悬浮窗 1 到新位置后，位置自动保存（以**屏幕百分比**存储）
- 下次打开串流界面时，自动恢复到上次位置
- 切换横竖屏时自动 clamp 到屏幕边界内

### 2.2 模式切换细节

- 缩放模式和触摸模式**互斥**，同时只有一个生效
- 再次点击已选中的模式不会取消
- 切换到缩放模式后，手指触摸屏幕将用于移动/缩放画面，不会发送鼠标事件

## 三、虚拟键盘

虚拟键盘 是一个**三行横向滚动**的按键面板，通过悬浮窗的键盘按钮控制显示/隐藏：

### 第一行：功能键
`F1 F2 F3 F4 F5 F6 F7 F8 F9 F10 F11 F12`

### 第二行：常用键
`长按 Esc Tab Ctrl Alt Shift Enter Win`

### 第三行：方向键 + 符号
`软键盘 ← → ↑ ↓ / \`

### 3.1 长按模式

点击**「长按」按钮**开启长按模式（按钮变蓝色）：

- 单击任意按键：**按住不松开**（按钮变淡蓝色，持续发送按键按下状态）
- 再次单击该按键：**松开**
- 可以同时按住多个按键（如 Ctrl+Shift+W）

### 3.2 长按模式 + 软键盘自动释放

当长按模式处于开启状态时：

1. **按下悬浮窗 2 的任意按键**（如 Ctrl）
2. **打开软键盘输入字符串**（如"abc"）
3. 输入完成后，**被按住的按键会自动抬起**（释放 Ctrl），但**长按模式按钮依然保持开启**


### 3.3 普通模式

长按模式关闭时，单击按键：快速按下→松开，相当于普通键盘按下。

切后台自动恢复串流

> 无需手动选择 PC → 选择游戏 → 点击恢复，全自动完成。

## 五、屏幕方向设置

路径：**基本设置 → 屏幕方向**

| 选项 | 说明 |
|------|------|
| 横屏 | 强制横屏模式 |
| 竖屏 | 强制竖屏模式 |
